# Amazon S3 (Simple Storage Service)

Amazon S3 is a **highly durable and scalable object storage** service designed to store and retrieve any amount of data from anywhere.

---

## 🔹 What is S3?

S3 stores data as **objects** inside **buckets**.  
Each object consists of data, metadata, and a unique key.

It’s built for **99.999999999% durability**, which is AWS saying: “We don’t lose your data.”

---

## ⭐ Key Features

- Unlimited storage capacity  
- High durability and availability  
- Versioning & lifecycle policies  
- Static website hosting  
- Fine-grained access control  

---

## 🧰 Common Use Cases

- Static website hosting  
- Backup and archiving  
- Media and asset storage  
- Data lakes  

---

## 🔐 Security & Access

- Bucket policies and IAM roles  
- Public access blocking  
- Server-side encryption  
- Access logging
