# Amazon EC2 (Elastic Compute Cloud)

Amazon EC2 provides **scalable virtual servers** in the cloud, allowing you to run applications without managing physical hardware.

---

## 🔹 What is EC2?

EC2 lets you launch virtual machines called **instances**.  
You choose the operating system, instance type, storage, and networking based on your workload.

It gives you **full control** over the server, just like a traditional machine — but in the cloud.

---

## ⚙️ Key Features

- On-demand and reserved instances  
- Multiple instance types (compute, memory, storage optimized)  
- Elastic Load Balancer integration  
- Auto Scaling support  
- Security Groups for firewall control  

---

## 🏗️ Common Use Cases

- Hosting web applications  
- Backend services and APIs  
- CI/CD build servers  
- Development and testing environments  

---

## 🔐 Security in EC2

- Security Groups act as virtual firewalls  
- Key pairs for secure SSH access  
- IAM roles for controlled AWS access  
- Network isolation using VPC
