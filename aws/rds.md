# Amazon RDS (Relational Database Service)

Amazon RDS is a **managed database service** that makes it easy to set up, operate, and scale relational databases in the cloud.

---

## 🔹 What is RDS?

RDS removes the headache of database management.  
AWS handles backups, patching, monitoring, and scaling — so you focus on data and applications.

---

## ⭐ Supported Engines

- MySQL  
- PostgreSQL  
- MariaDB  
- Oracle  
- SQL Server  

---

## 🧰 Common Use Cases

- Application databases  
- E-commerce platforms  
- Analytics workloads  
- Content management systems  

---

## 🔐 Security & Reliability

- Automated backups  
- Multi-AZ deployments  
- Encryption at rest & in transit  
- IAM authentication
