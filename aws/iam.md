# AWS IAM (Identity and Access Management)

AWS IAM controls **who can access what** in your AWS account.

---

## 🔹 What is IAM?

IAM lets you manage users, roles, and permissions securely without sharing credentials.

---

## ⭐ Core Components

- Users and groups  
- Roles and policies  
- JSON-based permission rules  

---

## 🔐 Security Best Practices

- Least privilege access  
- Use roles instead of access keys  
- Enable MFA  
- Rotate credentials regularly
