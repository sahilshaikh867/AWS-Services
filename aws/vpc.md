# Amazon VPC (Virtual Private Cloud)

Amazon VPC lets you create a **logically isolated network** within AWS where you control IP addressing, routing, and security.

---

## 🔹 What is VPC?

A VPC is your private network in the cloud.  
You decide who can talk to whom — and who stays locked out.

---

## ⭐ Core Components

- Subnets (public & private)  
- Route tables  
- Internet Gateway  
- NAT Gateway  
- Security Groups & NACLs  

---

## 🧰 Common Use Cases

- Secure application hosting  
- Network isolation  
- Hybrid cloud setups  
- Multi-tier architectures  

---

## 🔐 Security Model

- Security Groups (instance-level)  
- Network ACLs (subnet-level)  
- Private IP addressing
