# Amazon CloudFront

Amazon CloudFront is a **content delivery network (CDN)** that delivers content with low latency.

---

## 🔹 What is CloudFront?

CloudFront caches content at edge locations closer to users.

---

## ⭐ Key Features

- Global edge network  
- HTTPS and security features  
- Integration with S3 and ALB  

---

## 🧰 Common Use Cases

- Static website delivery  
- Media streaming  
- API acceleration  

---

## 💡 What I Learned

- How caching improves performance  
- CDN behavior and invalidations  
- Security benefits of edge delivery
