# Amazon SNS (Simple Notification Service)

Amazon SNS is a **pub/sub messaging service** for sending notifications.

---

## 🔹 What is SNS?

SNS pushes messages to subscribers instantly using topics.

---

## ⭐ Key Features

- Pub/Sub messaging  
- Multiple delivery protocols  
- High availability  

---

## 🧰 Common Use Cases

- Application alerts  
- System notifications  
- Event-driven workflows  

---

## 💡 What I Learned

- Topic-based messaging
