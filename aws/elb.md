# Elastic Load Balancing (ELB)

ELB automatically distributes incoming traffic across multiple targets to improve availability.

---

## 🔹 What is ELB?

ELB ensures no single server gets overloaded, improving reliability and performance.

---

## ⭐ Types of Load Balancers

- Application Load Balancer (ALB)  
- Network Load Balancer (NLB)  
- Gateway Load Balancer  

---

## 🧰 Common Use Cases

- High-availability web apps  
- Microservices architectures  
- Traffic routing
