# AWS Lambda (Serverless Compute)

AWS Lambda lets you run code **without provisioning or managing servers**.  
You pay only for the compute time you use.

---

## 🔹 What is Lambda?

Lambda executes functions in response to events.  
No servers. No scaling worries. Just code.

---

## ⭐ Key Features

- Automatic scaling  
- Pay-per-use pricing  
- Event-driven execution  
- Built-in fault tolerance  

---

## 🧰 Common Use Cases

- Backend APIs  
- Event processing  
- Automation tasks  
- Data transformation  

---

## 🔐 Security & Permissions

- IAM roles for execution  
- Resource-based policies  
- VPC integration for private access
